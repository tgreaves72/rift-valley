# Asset notes

The repository includes native geometric world/model data, rendered previews, generated promotional artwork, pass icons and four original synthesized WAV compositions. The new chase thumbnail is promotional illustration, not a Studio capture.

Production playback references four APMOfficial Roblox Creator Store releases by public asset ID. Their audio files are not redistributed here. Titles, sources and intended moods appear in [`assets/music/credits.json`](../assets/music/credits.json).

The included WAV files are separate project compositions described in [`assets/music/catalog.json`](../assets/music/catalog.json). They have not been uploaded as the production music assets.

The project uses Roblox's standard avatars, engine services, fonts and platform UI. It does not include Roblox software or toolchain executables. Generated preview helpers may use locally installed Windows fonts.

Original gameplay-style reference: [Huss Valley](https://www.roblox.com/games/107535308163741/Huss-Valley). The repository contains Rift Valley's implementation and assets; it does not contain the reference game's source or assets.
