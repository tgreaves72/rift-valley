OPTIONAL OPEN CLOUD VERSION UPLOAD
First create the experience in Studio. Obtain its universe ID and place ID from
Creator Dashboard. Create a scoped Open Cloud API key with place-publishing access
for that intended experience. Configure the credential through your local secrets
workflow; never commit or paste it into chat.
The script reads ROBLOX_UNIVERSE_ID, ROBLOX_PLACE_ID and ROBLOX_OPEN_CLOUD_API_KEY.
Run .\deploy\Publish.ps1 for a local dry-run.
Run .\deploy\Publish.ps1 -Publish -WhatIf to inspect the exact target action.
Run .\deploy\Publish.ps1 -Publish when you intend to upload that validated build.
The upload adds a published place version to the selected existing destination.
It does not create an experience or configure the audience, art, avatar, or size.
If the network response is uncertain, inspect version history before retrying.
